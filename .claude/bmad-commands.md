# Claude Code 中的 BMad 使用指南

## Windsurf IDE 集成

### 1. 代理调用方式
在 Windsurf 的 Claude Code 对话框中，可以直接使用以下代理命令：

```
@pm 分析提示词优化功能的用户需求
@architect 设计现代单页面应用的组件架构
@dev 实现响应式布局的最佳实践
@sm 制定现代化改造的4周计划
```

### 2. 快速命令
```
# 项目分析
/analyze 分析当前项目的技术栈和架构

# 现代化改造
/modernize 开始UI现代化改造流程

# 组件创建
/create-component [组件名] 创建现代组件模板

# 主题配置
/setup-theme 配置深色/浅色主题系统
```

### 3. 工作流示例

#### 现代化UI改造工作流
```
# 第1步：需求分析
@pm 分析PromptMaster Pro的UI现代化需求

# 第2步：架构设计  
@architect 设计现代单页面应用的组件架构

# 第3步：组件实现
@dev 实现ModernLayout.vue组件

# 第4步：主题配置
@dev 设置CSS变量和主题切换系统

# 第5步：测试计划
@sm 制定UI改造的测试和验收标准
```

## 项目特定配置

### 技术栈
- **前端**: Vue3 + TypeScript + Vite
- **UI库**: Element Plus + 现代组件
- **样式**: TailwindCSS + 自定义CSS变量
- **构建**: Monorepo (pnpm workspaces)

### 目录结构
```
packages/
├── web/          # 主应用
├── ui/           # 现代UI组件
└── core/         # 核心业务逻辑
```

### 代理专用提示词

#### @pm (产品经理)
```
你是一位专业的产品经理，负责PromptMaster Pro的UI现代化项目。
请提供：
1. 用户需求分析
2. 用户故事和验收标准  
3. 功能优先级排序
4. 用户体验优化建议
```

#### @architect (架构师)
```
你是一位前端架构师，专精Vue3和TypeScript。
请提供：
1. 现代化架构设计
2. 组件层次结构
3. 状态管理方案
4. 性能优化策略
```

#### @dev (开发工程师)
```
你是一位全栈开发工程师，负责实现具体功能。
请提供：
1. 代码实现示例
2. 最佳实践建议
3. 调试和测试方案
4. 性能优化代码
```

#### @sm (Scrum Master)
```
你是一位Scrum Master，负责项目管理。
请提供：
1. 开发计划和时间表
2. 任务分解和估算
3. 风险评估和缓解
4. 团队协作建议
```

## 使用场景

### 场景1: 创建新功能
```
@pm 我需要添加一个提示词模板库功能，请分析用户需求
@architect 基于需求设计组件架构
@dev 请提供具体的Vue3组件实现代码
@sm 制定2周开发计划
```

### 场景2: 重构现有代码
```
@architect 分析当前代码的架构问题
@dev 提供重构为现代组件的步骤
@sm 制定渐进式重构计划
```

### 场景3: 性能优化
```
@architect 分析当前性能瓶颈
@dev 提供优化代码和配置
@sm 制定优化时间表
```

## 快速开始

1. **打开 Windsurf IDE**
2. **启动 Claude Code 对话**
3. **使用代理命令**
   ```
   @pm 开始PromptMaster Pro的现代化UI改造需求分析
   ```

## 常用命令速查

| 命令 | 用途 | 示例 |
|------|------|------|
| `@pm` | 产品需求分析 | `@pm 分析用户界面需求` |
| `@architect` | 技术架构设计 | `@architect 设计响应式布局` |
| `@dev` | 代码实现 | `@dev 实现现代按钮组件` |
| `@sm` | 项目管理 | `@sm 制定开发计划` |
| `/analyze` | 项目分析 | `/analyze 当前项目状态` |
| `/modernize` | 开始改造 | `/modernize UI现代化` |

## 注意事项

1. **代理切换**: 使用不同代理时明确切换上下文
2. **详细描述**: 提供足够的上下文信息
3. **逐步进行**: 按照工作流逐步执行
4. **验证结果**: 每个步骤完成后验证效果
