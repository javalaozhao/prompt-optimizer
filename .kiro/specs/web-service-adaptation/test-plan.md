# 测试计划

## 测试目标

验证PromptMaster Pro Web服务版本的所有核心功能在移除桌面应用和Chrome插件相关组件后仍然正常工作。

## 测试环境

- **本地开发环境**: 使用`pnpm dev`命令启动
- **Docker环境**: 使用`docker-compose up`命令启动
- **浏览器**: Chrome最新版本
